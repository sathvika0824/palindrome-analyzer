# Palindrome Analyzer

This was my first ever programming project and my first solved problem on LeetCode.
A tiny Python project that checks whether a number is a palindrome.

## Problem
Check whether a given integer is a palindrome.

## Solution
- Negative numbers return False
- Reverse the number using string slicing
- Compare with original number

## Language
Python

## How to use
1. Clone the repo:
   ```
   git clone https://github.com/sathvika0824/palindrome-analyzer.git
   cd palindrome-analyzer
   ```
2. Run the program:
   ```
   python palindrome.py 121
   ```
   Output will say if the number is a palindrome.
